# Fraud Detection Model

## Overview
Machine learning project focused on identifying fraudulent financial transactions using classification models and data preprocessing techniques.

## Tools Used
- Python
- pandas
- scikit-learn
- matplotlib

## Models Used
- Logistic Regression
- SVM
- KNN
- Decision Tree (CART)

## Key Results
- Evaluated models using cross-validation and hyperparameter tuning
- Achieved strong classification performance with AUC scores above 0.90 for top-performing models
- Applied feature selection techniques including PCA, RFE, and SelectKBest
